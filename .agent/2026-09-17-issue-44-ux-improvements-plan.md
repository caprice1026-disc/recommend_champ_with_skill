# Issue #44 UX改善 実装計画

## 目的

現行のCloudflare版LoLスキルラボについて、診断開始前の入力確認、準備画面の戻る操作、診断中断、保存状態、通信失敗、結果の次アクション、モーダル操作を、画面文言と実際の状態遷移が一致するように整える。

## 対象

- `src/client/App.tsx`
  - 実入力を伴う環境チェック
  - 準備画面の回答・スキップ保持と戻る操作
  - 詳細判定・再テストの中断復帰
  - 新しい結果への保存状態の引き継ぎ防止
  - 保存・削除・フィードバックの処理中／失敗復帰
  - レーン絞り込み、低信頼テストへの導線、推薦カードの考察・練習導線
  - モーダルのEscape・フォーカス復帰・ARIA
- `src/client/styles.css`
  - 新しい状態・導線・狭い画面での表示
- `src/client/__tests__/App.test.tsx`
  - 実入力必須化と、回答後のスキップで回答が残らないことの回帰テスト
- `README.md`
  - 中断、保存、再試行、モーダル操作の仕様説明

## 完了条件

- READY表示がタイマーだけで変化せず、ポインタークリックとQWER入力を実測する。
- 回答・スキップ・戻る操作の状態が一致し、保存済み結果と再計算後の結果を区別する。
- 詳細判定・再テストの中断時に直前の確定結果を維持する。
- 保存・削除・フィードバックの失敗時に結果または入力を失わず、連打を抑止する。
- `npm.cmd run lint`、`npm.cmd run test:run`、`npm.cmd run build`、設定・カタログ検証が通る。
